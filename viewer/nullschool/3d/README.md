# Three.js 三维气象预览

入口：<http://127.0.0.1:8080/3d/>。和经典页面共用 `weather-earth serve --port 8080`、GFS 快照以及每 30 分钟的数据更新。

默认底图为 Google 实景三维。大阪入口：<http://127.0.0.1:8080/3d/?view=osaka&basemap=google&level=850hPa>。菜单“大阪实景”定位到中之岛附近；“卫星地形”或 `basemap=terrain` 可切回 Cesium 地形、Esri 影像和 OSM 建筑。

## 已接入

- Three.js 0.187.0 + 3d-tiles-renderer 0.5.4；统一三维相机、深度和地形/影像渲染。
- Google Maps Photorealistic 3D Tiles（Cesium ion 资产 2275207）：完整的带纹理地表和城市模型，保留源模型的屋顶、立面纹理与材质。
- Cesium World Terrain：读取已有 `viewer/earth.config.local.js` 的配置，服务端换取临时地形令牌；不把长期令牌写入新页面或代码仓库。
- Esri World Imagery 卫星底图。
- Cesium OSM Buildings（资产 96188）：独立的三维建筑图层，沿用现有 Cesium 授权；保留 OpenStreetMap 归因和供方账户提示。
- Natural Earth 国家边界，以及 DataV 中国省、市级/省直辖行政单元边界。原始来源和转换说明在 `../data/geography/sources.json`。
- Sfc 与七个等压层的 GFS 风温数据，温度栅格切片、点位插值与风线动画。风线使用同批次 HGT 位势高度，使用地表气压屏蔽地下气压层。
- NASA GIBS Himawari AHI 红外云图，按源站最新观测时间取图，每 5 分钟检查。
- 全球、中国、珠峰近景、风层侧视、西安城区及建筑近景预设；左键移动、滚轮缩放、右键倾斜。

## 构建和数据准备

```bash
cd viewer/nullschool/3d
npm ci
npm run build
```

`vendor.js` 是固定版本依赖的浏览器 bundle，随源码保留，运行预览不需要依赖外部 JavaScript CDN。

在仓库根目录更新行政区数据：

```bash
.venv/bin/python -m weather_geo_extractor.earth_layers prepare-admin
```

`data/earth3d-cache/` 为可再生的气象 PNG 瓦片缓存，已被 Git 忽略。下载的行政区 GeoJSON 与来源记录位于 `data/geography/`。

## 表达范围

实景三维使用既有 `viewer/earth.config.local.js` 中的 `cesiumIonToken` 换取 Google 可视化入口。服务端 `/api/earth/3d/photorealistic` 不返回长期账户令牌，HTTP 响应为 `no-store`；客户端使用官方 Google 会话插件处理后续请求，凭据仅发送到 HTTPS 的 `tile.googleapis.com`。Google 模型不进入 Esri 的压缩响应/预览缓存，也不进入本地地形文件缓存，网络请求遵循源站 HTTP 缓存策略。渲染器活动资源缓存上限约 512 MiB，最近离开视野的瓦片使用已有的软保留策略。

该模式使用 Google 自带的完整三维底图，不叠加 OSM 白模、Esri 底图或 Cesium 地形。风场、气温和行政边界仍可叠加；天气图层不改写原有摄影纹理或驱动模型额外细分。Google Maps 标志、当前可见瓦片的数据归因以及 Cesium 账户提示保留在页面下方。API 与 Google Earth 产品的覆盖、影像日期、标签和渲染表现不保证完全一致，未覆盖区域不会补造建筑纹理。

OSM 建筑入口：`/3d/?view=buildings&basemap=terrain&buildings=1`。建筑形状与高度来自 Cesium OSM Buildings，数据覆盖和完整度随地区变化；未覆盖的位置仍显示卫星影像。建筑和底图是独立的数据层，页面不补造缺失建筑。点选建筑时显示的是模型表面的近似高程，而非离地建筑高度。

建筑在相机高度低于 80 km 时开始加载，超过 100 km 时暂停；独立缓存上限为 128 MiB，最多四路下载和两路模型解析，关闭图层会释放资源。关闭真实地形时暂停建筑；在地形关闭状态下开启建筑会同时开启真实地形。长期账户令牌留在服务端，浏览器只取得建筑资产的临时令牌，授权请求仅发给资产对应源站。

Draco 与 Meshopt 解码支持随前端依赖一起提供，Draco 解码文件在 `decoders/draco/`，许可证在 `licenses/` 和 `THIRD-PARTY-NOTICES.txt`。`npm run build` 同时更新依赖包和本地 Draco 文件。

供方归因图标使用 `https://assets.ion.cesium.com/ion-credit.png` 的完整本地副本，避免图标网络超时；数据来源链接与账户提示仍按供方返回内容显示。

真实三维地形来自高程瓦片。风线按 GFS 各等压面的 HGT 位势高度换算近似几何高度；Sfc 使用 GFS 地形以上 10 m。GFS 的 0.5° 地形与高精度地形并不完全相同，贴近山地时部分地面风线会被地形遮挡。地下等压层由同批次地表气压和高度共同屏蔽。风速动画经过时间缩放，目前仍为各层水平风，没有垂直速度或连续三维流场。

“风层高度放大”默认 1×；1–20× 只改变风层离地的显示距离，不改变风速、风向和点位报告的原始位势高度。使用“风层侧视”可以比较 850/500/250 hPa 等层的离地距离。温度颜色仍投影在地形表面。

风粒子按当前屏幕分区，通过相机射线在实际 HGT 风层上取点，覆盖倾斜视角、宽屏两侧和地平线附近。旋转、缩放或改变窗口比例后使用新的视野补充粒子；移出原屏幕区域的粒子重新生成，避免长时间平流后聚集在画面一侧。天空、地球背面、地下等压层及源数据缺测处不会人为补画风线。

高度辅助数据从当前风场快照对应的 NOAA GFS 原文件按需下载，缓存至 `data/earth3d-cache/height/`。网格、起报及有效时间必须与风场一致。首次切换可能需要等待下载；失败时暂停该层风线并显示重试，不回填其他时次或固定高度。

云图是带观测时间的红外影像，覆盖东亚/西太平洋；其延迟由提供方决定。元数据会在本地保留，更新失败时沿用上次观测时刻并明确显示缓存状态；影像瓦片仍需访问 NASA GIBS。卫星底图不是实时影像。

## 兼容适配

以下卫星影像细分与本地瓦片缓存策略用于“卫星地形”模式；Google 实景三维使用自身的三维瓦片树与原始摄影纹理。

`overlays.js` 为固定的 3d-tiles-renderer 0.5.4 补齐区域覆盖层缺失时的 uniform 槽，并保护瓦片/覆盖层取消后的回调。地形几何不等待叠加层下载，先显示本地低精度底图，再补齐卫星影像。只初始化开启的图层和视野内的影像，行政边界及气温纹理使用 256 像素，卫星影像使用 512 像素。

卫星影像单独驱动叶节点细分，目标约为一个物理屏幕像素对应一个纹理像素；天气与行政区开关不重建该细分树。卫星源最多请求到 19 级，使用 mipmap 和最高 8× 各向异性过滤改善斜视清晰度，渲染像素比最高为 2。单帧最多处理两次额外细分，保留已加载祖先作为后备。

原地旋转时，额外细分会等待相机稳定 250 ms；已展开的层级使用滞后区间，避免在误差阈值附近反复切换。最近离开视野的已加载瓦片有 20 秒软保留期，硬缓存容量仍优先执行。卫星图另有 64 MiB 的压缩响应缓存，命中后直接复用，不再排队访问远端。

已加载影像保留在最多 32 MiB 的低分辨率预览缓存中。新瓦片先使用覆盖其地理范围的已有影像，按相同地图投影重新计算纹理坐标，高清纹理就绪后自然覆盖。下载优先级随当前可见区域更新；已准备好的纹理不再等待其他不可见区域的下载。

影像请求在离开下载队列后才开始计算 20 秒超时，并允许一次重试；失败瓦片每 20 秒重试，也可手动重试。地形目录 `layer.json` 在服务端单独缓存一小时并在启动时预热；缓存中不包含访问令牌，目录失败时允许浏览器直连原服务。凭据仍通过现有配置换取临时令牌，含令牌接口保持 `no-store`。地形和影像的首次下载速度仍受外部服务影响。

地形瓦片通过限定源的本地接口按需缓存，缓存命中不再访问远端。文件有效期一天，目录位于 `data/earth3d-cache/terrain-tiles/`，约 256 MiB 的容量阈值按分钟检查并清理较旧瓦片；浏览器可缓存成功响应一小时，错误响应不缓存。缓存键包含数据源、瓦片模板和扩展协议，文件中只保存地形数据，不保存令牌。缓存通道不可用时仍可直连原地形服务。

更新加载器版本时应重新验证：全球与区域图层混合、快速切换气压、云图刷新、地形开关、城市放大及外部地图服务中断。可用 `?view=city&debug=1` 和 `window.weatherEarth3D.captureMetrics()` 检查首块地形、影像级别、缓存估算、可见瓦片及待完成请求；普通页面不显示调试数据。

失败重试只处理已初始化的瓦片，避免 0.5.4 对外部索引中的原始子节点直接读取 `internal.loadingState` 而中断渲染。建筑更新异常会单独释放建筑层并安排重试，地形与风场渲染继续运行。

兜底球体的颜色先绘制，地形随后覆盖，最后单独补充遮挡深度；避免粗级别地形的平面三角形落入光滑球体内部时出现斑块，同时保留缺瓦片区域对背面风线的遮挡。

验证：仓库根目录运行 `pytest tests/test_earth_heights.py tests/test_earth_data.py tests/test_earth_layers.py tests/test_earth_buildings.py tests/test_earth_server.py`；本目录运行 `npm test`。视野覆盖测试包含倾斜、宽屏/竖屏、旋转/缩放、日期变更线、极区、缺测与背面遮挡；建筑测试覆盖城市尺度加载、独立缓存、关闭释放、异步切换和令牌作用域。
