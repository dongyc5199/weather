以作者公开的 [cambecc/earth](https://github.com/cambecc/earth) 为风场可视化基础。

- 来源校验：`upstream.json` 记录导入时各文件的 SHA-256，适配后的文件可据此识别。
- 此目录是 vendored 源码，不含嵌套 Git 仓库。现有 Cesium、MapLibre 和 Python 数据处理代码继续独立使用。

## 启动

在 weather 项目根目录、已激活的 Python 虚拟环境中运行：

```bash
python -m pip install -e ".[weather]"
weather-earth serve --port 8080
```

打开 <http://127.0.0.1:8080/>。服务会在启动时下载或复用最近的完整 GFS 数据，并在运行期间每 30 分钟检查更新。不需要安装上游 Express、Grunt 等 Node 依赖，也不需要 API key。

只下载一次：

```bash
weather-earth sync
```

`--refresh-seconds 1800` 控制服务端检查间隔；设为 `0` 关闭周期检查（保留启动检查与手动刷新）。`--viewer-root` 可显式指定此目录。

如果只需读取已下载的快照，可以继续使用 `python3 -m http.server 8080 --bind 127.0.0.1 --directory viewer/nullschool`，或通过已有的 `weather-geo serve-map --port 8765` 打开 <http://127.0.0.1:8765/viewer/nullschool/>。静态服务不会自动下载新数据。

## 本次可用范围

页面默认朝向亚洲。点击左下角 `earth` 展开菜单，可切换 Air/Ocean、Height、Wind/Temp/None、Grid 和地图投影。Height 支持 Sfc、1000、850、700、500、250、70、10 hPa。拖动旋转、滚轮缩放；点击地图查询坐标、风向、风速和气温，点击单位切换显示单位。视角、高度和图层记录在 URL hash 中。

`Latest` 手动检查新数据。`Run` 是模式起报时间，`Date` 是所显示预报的有效时间，两者随 Local/UTC 切换。数据是数值预报，动画移动不代表天气时间正在推进。

| 数据 | 时间与网格 |
| --- | --- |
| 地面风 | 最新可用 GFS 批次，10 米 U/V 风，0.5° 显示网格，720 × 361 |
| 气温 | 与风场相同批次、相同有效时间的 2 米气温；原始单位 K，前端可显示 ℃/℉/K |
| 等压层风场/气温 | 1000、850、700、500、250、70、10 hPa，每层各自读取 U、V、TMP 三条 GRIB 记录，使用同一批次和有效时间 |
| 洋流 | OSCAR，2014-01-31 样例，文件名分辨率 0.33° |
| 离线风场样例 | GFS，1° 网格，360 × 181；起报 2014-01-31 00:00 UTC，有效时间 03:00 UTC |

有有效 GFS 缓存时，URL 中的 `current` 指向缓存清单中的不可变快照；首次运行且尚未取得数据时，地面层显示历史样例并标注，等压层链接等待所选层下载完成。按钮只在对应数据可用时启用。更新失败不替换已有快照，页面显示缓存提示并保留真实时间。Ocean 始终标注为历史样例。湿度和任意历史/未来时刻浏览尚未接入。

等压层不是固定海拔，也不是地面天气的缩放。数据按原始 GFS 气压层提取，GRIB 固定层压力以 Pa 保存（例如 1000 hPa = 100000 Pa），界面用 hPa 显示；源数据若带缺测掩码，保留为 `null`，不填成零。

## GFS 数据链路

源：[NOAA GFS 官方开放数据](https://registry.opendata.aws/noaa-gfs-bdp-pds/)，首选 NOAA 的公开 S3 数据镜像，索引发现失败时尝试 [NOMADS](https://nomads.ncep.noaa.gov/)。

1. 从当前 UTC 小时向前检查最新 00/06/12/18 UTC 批次，最多回看 8 个批次。选择该批次对当前整点的预报；新批次尚未发布完整索引时回退到上一批次。
2. 读取 `.idx`，精确选择地面的 `UGRD:10 m above ground`、`VGRD:10 m above ground`、`TMP:2 m above ground`，以及七个等压层上各自的 UGRD/VGRD/TMP。
3. 用 HTTP Range 只下载 24 个 GRIB2 消息，不下载完整的数百 MB 预报文件；拒绝忽略 Range 的响应。
4. ecCodes 解码并检查变量、高度、单位、起报/有效时间和网格方向。0.25° 原网格每隔一个点抽样为 0.5°，保留真实 U/V 与 Kelvin 数值，输出保留三位小数。这是显示抽样，不是增加预报精度。
5. 所有高度的风场与气温完成一致性校验后，写入同一不可变目录的 16 个 JSON 文件，最后原子替换 `data/live/manifest.json`。任一层失败都不发布半套数据。清单保留来源 URL、时间、高度清单、尺寸、SHA-256 和下载字节数。

完整高度快照使用 schema 2 和带 `-v2` 后缀的目录，保留旧地面快照。旧缓存可以继续读取，但不会被误认为已包含高空层；首次升级会重新获取完整数据。

缓存目录 `data/live/` 已被 Git 忽略。保留上次成功的数据用于断网阅读；缓存不会通过本次修改上传或提交。

后端代码：`src/weather_geo_extractor/earth_data.py`（发现、解码、发布）和 `earth_server.py`（本地服务与检查更新）。前端 `live-data.js` 管理快照和数据状态；`products.js` 将 `current` 解析到完整快照。

## 本地适配

1. `index.html` 使用仓库附带的 Underscore、Backbone、TopoJSON、D3；图形、字体和数据均从本地加载。
2. 页面和共享样式表的资源路径改为相对路径；`micro.js` 的 `assetUrl()` 从脚本 URL 解析数据根目录，`products.js` 复用它。
3. 首屏默认亚洲视角；显示数据状态、所选高度、起报时间和有效时间；开放已完成下载的风速、气温及高度选项，任意时次入口继续关闭。
4. 关于页说明本地数据范围，移除上游分析统计脚本；菜单可在嵌入预览内直接使用。
5. 原有投影、风场插值、粒子和颜色渲染算法保留。样式继续使用上游共享 `styles/styles.css`。
6. 窗口/侧栏尺寸变化时重建画布和屏幕风场，保留朝向与相对缩放，避免旧版固定画布在窄窗口溢出。
7. 拖动/缩放时仅暂停风线；温度等颜色覆盖层通过独立的限分辨率重投影持续更新，松手后恢复完整精度和粒子动画。预览沿用同一数据、色带和透明度，不固定旧画面，也不需要重新下载数据。
8. 面板与点位信息采用共享样式变量：桌面正文 16px、面板最大宽度 528px、窄屏正文 14px；`earth` 开关放在面板下方。色带跟随实际内容宽度绘制，短窗口可在面板内滚动。
9. 切换气压层、数据时次或批次时立即取消旧风场任务并清空风线画布；新场从空白画布开始绘制，不保留渐退残影。等待新数据期间的拖动重绘也不会重新启动旧风线。

## 后续数据接入边界

这套开源引擎使用 GRIB 风格 JSON 网格，不直接支持现官网的 `.epak` 二进制数据。最新 GFS 来自 NOAA 官方源，没有调用 Nullschool 官网的私有接口。

现有项目输出的风区 GeoJSON 是面要素；驱动粒子动画需要规则网格上的 U/V 风速分量，不能把风区轮廓直接当作风场。接入业务 GeoJSON 需要另加叠加层。
