# 夜间观测台 · 样式文档

面向气象爱好者的地球天气平台视觉规范。界面像仪器面板一样退到后面，让大气数据自己发光。

## 1. 设计原则

1. **界面中性，数据发光。** 数据色带已经非常饱和，界面色只用深色中性色，品牌色只做点睛。
2. **读数是仪器，不是装饰。** 时间、hPa、位势高度、风速一律使用等宽字体，数值用主色，单位用次要色。
3. **一屏一个记忆点。** 记忆点是地球上流动的风线与急流，其余元素保持安静。
4. **动效回应操作。** 切换、点击、取点都有过渡；持续动态只保留风线流动和探针脉冲。

## 2. 颜色

| 角色 | Token | 值 |
|---|---|---|
| 画布背景 | `--space` | `#05060A` |
| 面板 | `--panel` | `#0E1014` |
| 浮层 / 悬停 | `--raised` | `#171A20` |
| 描边 | `--hairline` | `rgba(255,255,255,.07)` |
| 主文字 | `--text` | `#E8E9EC` |
| 次要文字 / 单位 | `--muted` | `#8A909B` |
| 选中态胶囊 | `--chip` | `#F4F4F1`（深色字） |
| 品牌强调 / 等值线 | `--amber` | `#F2B84B` |

使用比例：中性色约 92%，琥珀色约 6%，其余是数据本身的颜色。

### 要素语义色

只用于图层图标、图例小点，不要大面积铺。

| 要素 | Token | 值 |
|---|---|---|
| 风 | `--c-wind` | `#5CC8FF` |
| 气温 | `--c-temp` | `#FF7A59` |
| 气压 | `--c-press` | `#F2B84B` |
| 云 | `--c-cloud` | `#BFD4E6` |
| 降水 | `--c-rain` | `#3DD6C6` |

### 数据色带

- **观测台色带**（`--ramp-wind`）：深海军蓝 → 青 → 黄绿 → 橙 → 品红 → 近白。低值淡入背景，强风和急流跳出来。
- **经典色带**：在观测台色带基础上提高饱和度并偏移色相，贴近爱好者熟悉的风速图。
- **气温色带**（`--ramp-temp`）：蓝 → 青 → 近白 → 黄 → 红。
- 彩虹类色带感知不均匀，必须允许一键切换，并在图例上保留精确刻度。后续建议增加 viridis / turbo 等色盲友好选项。

## 3. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 中文 | Noto Sans SC（可换 HarmonyOS Sans SC） | 标题 600，正文 400 |
| 西文 UI | Geist | 界面通用 |
| 数据与读数 | Geist Mono | 开启 `tabular-nums` |

字号层级：10 / 11 / 12 / 13 / 16 / 22。多用字重和灰度拉开层级，少用字号。字标 `earth` 为占位，正式上线前建议做定制字标并更换名称。

## 4. 形状与间距

- 圆角：面板 16px（`--r-panel`），控件 10px（`--r-ctrl`），胶囊 999px（`--r-pill`）。
- 描边：1px 半透明白色（`--hairline`）。
- 面板：`rgba(14,16,20,.82)` 加 `backdrop-filter: blur(14px)`，轻微毛玻璃。
- 间距：以 4px 为基数，面板内边距 12 至 20px，行间距 16px。

## 5. 组件

| 组件 | 类名 | 说明 |
|---|---|---|
| 面板 | `.panel` | 所有浮层的基础样式 |
| 胶囊按钮 | `.chip` | 选中态为 `.on` 或单选框选中后的 `.hid:checked + .chip` |
| 分段控件 | `.seg` `.tab` `.pill` | 滑块用 `--t` 控制位置 |
| 气压层高度轨 | `.rail` `.lvl` `.pill2` | 滑块用 `--i` 控制位置，每档高度 32px |
| 图层行 | `.row` `.lab` `.dot` | 关闭图层后语义色小点变暗 |
| 探针读数卡 | `.probe` | 跟随点击位置，右半边自动翻到左侧 |
| 图例 | `.legend` `.lg` | 风速与气温两套图例交叉淡入淡出 |
| 时间轴 | `.timeline` `.track` | 播放时进度条与圆点沿时间线移动 |

状态由隐藏的 `input`（类名 `.hid`）加 CSS `:has()` 驱动，不依赖 JavaScript。

## 6. 动效

| 场景 | 时长 / 曲线 |
|---|---|
| 按钮悬停、选中 | 200ms，默认缓动 |
| 按钮按下 | 缩放到 0.95，150ms |
| 分段控件、气压层滑块 | 400ms，`--spring`（轻微回弹） |
| 图层淡入淡出、填色切换 | 600ms，ease |
| 切换气压层的地球亮度与饱和度 | 600ms，ease |
| 探针移动 | 450ms，`--ease` |
| 点击涟漪 | 800ms，ease-out |
| 风线流动 | 2.6s 线性循环 |
| 探针脉冲环 | 1.8s 循环 |
| 面板入场 | 600ms，上浮 10px 并淡入 |
| 时间轴播放 | 10s 线性循环，可暂停 |

系统开启「减少动态效果」时，所有动画与过渡自动关闭。

## 7. 无障碍

- 所有控件使用真实的 `button`、`input` 与 `label`，键盘聚焦显示琥珀色 2px 轮廓。
- 图标按钮带 `aria-label`，探针读数区域为 `aria-live="polite"`。
- 次要文字 `#8A909B` 在 `#0E1014` 面板上对比度满足 4.5:1。
- 小于 1000px 宽时布局改为单列堆叠。

## 8. 对接真实数据时需要替换的部分

- 地球目前是 SVG 示意图，不是真实渲染。需要接入真实的投影与风场粒子数据。
- `script.js` 中的 `sample()` 是按位置估算的演示值，需要替换为真实的格点插值。
- 切换气压层目前只改变地球的亮度与饱和度，真实产品应加载对应层的数据。
- 「地图」「样式」两个标签尚无对应的面板内容；底部时间轴的「+3 h」与时间读数需要与数据时次联动。
